# Track Banana Legal Pages

Static legal pages for the Track Banana shared house and personal expense manager, following the simple GitHub Pages setup used by `Vertical_Cut_Legal`.

## Pages

- `index.html`
- `privacy-policy.html`
- `terms-and-conditions.html`
- `account-deletion.html`

## GitHub Pages URLs

For the `Mangoo0110/track_banana_legal` repository, with Pages publishing from `main` and `/(root)`, the URLs are:

- Privacy Policy: `https://mangoo0110.github.io/track_banana_legal/privacy-policy.html`
- Terms and Conditions: `https://mangoo0110.github.io/track_banana_legal/terms-and-conditions.html`
- Account deletion: `https://mangoo0110.github.io/track_banana_legal/account-deletion.html`

To update the live pages, upload the files from this folder into the repository root and commit the changes in GitHub. GitHub Pages will redeploy from the saved branch source.

## Before using these pages

Confirm the developer name, support email, age policy, and data handling statements match the Track Banana app and its Play Store listing. The deletion text reflects the current app behavior, which removes personal expenses and preserves some shared-house history. Keep this site and the app's Google Play Data safety answers in sync as the app changes.
