# Aanda Legal Pages

Static legal pages for the Aanda shared house and personal expense manager, following the simple GitHub Pages setup used by `Vertical_Cut_Legal`.

## Pages

- `index.html`
- `privacy-policy.html`
- `terms-and-conditions.html`
- `account-deletion.html`

## Publish with GitHub Pages

For the simplest standalone setup, create a public GitHub repository named `aanda-legal`, copy the contents of this directory into the repository root, then open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save. GitHub Pages will publish the static files at `https://mangoo0110.github.io/aanda-legal/` after deployment. The URLs will be:

- Privacy Policy: `https://mangoo0110.github.io/aanda-legal/privacy-policy.html`
- Terms and Conditions: `https://mangoo0110.github.io/aanda-legal/terms-and-conditions.html`
- Account deletion: `https://mangoo0110.github.io/aanda-legal/account-deletion.html`

The repository name and GitHub account name determine the final URLs. If you use a different owner or repository name, update these example URLs accordingly. GitHub Pages is available for public repositories on GitHub Free.

## Before publishing

Confirm the public developer name, support email, age policy, and data handling statements match the app and Play Store listing. The deletion text reflects the current Aanda backend behavior, which anonymizes the profile while preserving some shared-house history. Keep this site and the app's Google Play Data safety answers in sync as the app changes.
